**Hranix Shield** — бесплатная панель безопасности с открытым кодом для Windows, которая
объединяет инструменты уровня предприятия — **CrowdSec, Osquery, ClamAV, Wazuh, restic** —
в одном понятном дашборде **на вашем же компьютере**.

Без облака. Без телеметрии. Данные не покидают ваш компьютер.

## Зачем Hranix Shield

CrowdSec и Wazuh мощны — и враждебны к неспециалисту. Hranix Shield не заменяет их, а
**упаковывает**: поставил один раз — понял с первого взгляда.

- 🔥 **Защита периметра** — состояние фаервола ОС, открытые порты (по процессам), правила,
  блокировка/разблокировка в один клик (с настоящим запросом прав администратора — права
  никогда не кэшируются).
- 🛰️ **Обнаружение вторжений** — CrowdSec: баны и реальные попытки атак на эту машину.
- 🦠 **Вирусная активность** — проверки ClamAV (быстрая/полная/папка), карантин с
  восстановлением, история сканирований.
- 📡 **Сеть** — живая таблица соединений (процесс, адрес, страна), офлайн GeoIP-карта мира,
  блокировка IP / завершение процесса с многоступенчатым подтверждением.
- 💾 **Резервные копии** — restic: по расписанию (ежедневно в 04:00) + вручную, проверка
  целостности с автовосстановлением при повреждении.
- 📋 **Журналы ОС** — FIM-события Wazuh с серьёзностью, фильтрами, экспортом CSV/JSON.
- 🩺 **Здоровье системы** — статусы подсистем, история метрик, обезличенный диагностический
  отчёт.

**Честность по построению:** если что-то не настроено — панель так и говорит и объясняет,
как починить; у неактивной кнопки всегда есть объяснение причины. Фальшивое «всё спокойно»
считается багом.

## Установка (Windows)

> Windows 10/11 x64, права администратора. Язык панели: русский / английский
> (переключатель в шапке).

1. Скачайте `hranix-shield-setup.exe` со страницы
   [**Releases**](../../releases).
2. Запустите и подтвердите запрос UAC. Приложение установится в
   `C:\Program Files\Hranix Shield` и запустится автоматически (иконка в трее).
3. Откройте панель: иконка в трее → **«Открыть панель»**, или
   <http://127.0.0.1:8080>.

### Создайте аккаунт администратора

Публичной регистрации в панели нет. До (или сразу после) первого запуска создайте файл
`%LOCALAPPDATA%\Hranix\Hranix Shield\config.env`:

```ini
BOOTSTRAP_ADMIN_USERNAME=ваш-логин
BOOTSTRAP_ADMIN_PASSWORD=ваш-надёжный-пароль
```

Перезапустите приложение (трей → Выход → запустить снова) и войдите.

### Из коробки и по кнопке

| Работает сразу | Включается одной кнопкой (нужен Docker Desktop) |
|---|---|
| Фаервол, порты, правила | Обнаружение вторжений (CrowdSec) |
| Сетевые соединения, GeoIP-карта | Антивирус (ClamAV) |
| Телеметрия процессов ОС | Журналы ОС / FIM (Wazuh) |
| Резервные копии (restic в комплекте) | |

Для второй колонки: установите
[Docker Desktop](https://www.docker.com/products/docker-desktop/), затем в панели
**Настройки → Стек защиты → Развернуть**. Приложение само сгенерирует конфиги и секреты,
поднимет инструменты и пропишет себе учётные данные — после чего попросит перезапуск.

## Docker Compose (для опытных)

```bash
docker compose up -d                          # панель (127.0.0.1:8080)
docker compose -f infra/security/crowdsec/docker-compose.yml up -d
docker compose -f infra/security/clamav/docker-compose.yml  up -d
docker compose -f infra/security/wazuh/docker-compose.yml   up -d
```

Примечание: в Docker-режиме консоли «Периметр» и «Сеть» видят контейнер, а не ваш хост —
для полной функциональности используйте нативный инсталлятор.

## Сборка из исходников

```bash
git clone https://github.com/hranix-shield/hranix-shield.git
cd hranix-shield
python -m venv .venv && .venv/Scripts/pip install -r server/requirements-packaged.txt
cd server && ../.venv/Scripts/python -m pytest -q     # unit-тесты, полностью офлайн
```

Сборочные артефакты для Windows выпускает `.github/workflows/windows-build.yml`.
Упаковка macOS (`.app`/`.dmg`) и Linux (`.deb` + systemd) — в каталоге `packaging/`.

## Приватность

- Панель привязана только к **127.0.0.1**.
- **Ноль телеметрии.** Единственный «отчёт» — обезличенный диагностический бандл, который
  вы явно сохраняете локально.
- Копии шифруются (restic); секреты живут в профиле пользователя и не уходят в облако.

## Лицензия

- Код: **AGPLv3** — см. [LICENSE](LICENSE); вклад принимается по
  [CLA](CLA.md).
- Сторонние компоненты: Osquery (Apache-2.0), restic (BSD-2), CrowdSec (MIT) — вендорятся;
  Wazuh и ClamAV (GPLv2) работают **отдельными контейнерами/сервисами** и никогда не
  линкуются с этим кодом.
- Инструменты и модели с несвободными лицензиями (Picovoice, готовые модели openWakeWord)
  не используются вообще.
